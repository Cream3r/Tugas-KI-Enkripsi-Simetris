Kembalikan berkas asli

Dekripsi hanya tersedia untuk berkas milik akun Anda yang masih tersimpan di aplikasi.

Unggah file .enc atau gambar terenkripsi yang sebelumnya diunduh dari aplikasi ini. Algoritma dikenali otomatis, dan file asli akan diunduh dengan nama serta ekstensi semula.

Gunakan gambar terenkripsi yang masih utuh. Mengedit, menyimpan ulang, atau mengompres gambar dapat menghilangkan data untuk dekripsi.

File .bin lama dapat didekripsi melalui daftar file yang masih tersimpan di aplikasi. File .bin yang berdiri sendiri tidak memuat metadata dan IV untuk dekripsi AES/DES.
