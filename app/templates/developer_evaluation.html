Evaluasi cipher

Ukur performa, penyimpanan, keutuhan, dan perilaku keamanan AES, DES, serta RC4 pada input yang sama.

Konfigurasi pengujian

Gunakan profil JSON, KTP simulasi, PDF, Word, Excel, atau video. Maksimal 16 MiB; total ukuran × (pengulangan + 2 pemanasan) maksimal 256 MiB per cipher. Sampel sintetis mewakili ukuran, bukan dokumen/video yang dapat dibuka.

Metode dan batas interpretasi
  • Dua pemanasan per cipher, lalu urutan AES/DES/RC4 diacak pada setiap pengulangan dengan seed 2026.
  • Waktu memakai perf_counter_ns, meliputi inisialisasi cipher, IV acak dan padding. Dekripsi meliputi unpadding. Hash diperiksa di luar interval waktu.
  • Upload, disk, database, jaringan, rendering, dan uji keamanan tidak masuk statistik waktu cipher.
  • Untuk perbandingan andal, tutup beban latar, gunakan perangkat dan input yang sama, lalu ulangi beberapa sesi. P95 pada sedikit pengulangan memiliki resolusi terbatas.
  • Data unggahan hanya digunakan di memori untuk laporan; laporan tidak disimpan server. Uji otorisasi menggunakan fixture sementara, bukan database atau file pengguna.
  • Ekspor JSON menjalankan pengujian baru dan menyertakan seluruh sampel waktu. Hindari nama file sensitif saat membagikan laporan.
